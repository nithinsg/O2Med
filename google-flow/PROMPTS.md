# AirO2 Stride: Google Flow image prompts

Eight images: four for the landing-page carousel (needed) and four for the "Who is the oxygen for?" cards (optional, but they make the finder feel premium).

## How to use this pack

1. Open Google Flow and create a new **image** (not video).
2. For each prompt below, upload the reference images listed under **Attach**, in the order given, as ingredients or references. If Flow limits how many you can attach, use the first ones listed; they matter most.
3. Paste the **Prompt** text exactly. Set the aspect ratio to **portrait 3:4**, or 9:16 if 3:4 isn't offered, and I'll crop it.
4. Generate 4 variations and pick the one where the **device shape** and the **nasal cannula** look right (see the checklist under each prompt).
5. Save it with the **Save as** filename and send it back to me. I'll drop it straight into the site.

**About the logo:** AI image tools often garble small logo text. Don't reject an otherwise great image for that. I'll stamp the real AirO2 logo onto the device afterwards, as I did with the product photos.
